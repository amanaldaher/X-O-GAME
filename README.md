A modern, responsive, and aesthetically pleasing X O GAME web application crafted with a custom dark emerald & sage-green glassmorphism aesthetic.

The project features multiple gameplay modes, an intelligent automated AI opponent, per-user high score persistence, and a touch-optimized responsive layout for seamless gaming across all devices.

## 📌 Features

- **Dual Game Modes:** Supports both local 2-Player pass-and-play (`PvP`) and Single Player against an intelligent AI bot (`Vs AI`).
- **Strategic AI Opponent:** Features real-time move validation that identifies winning strikes, blocks opponent victories, prioritizes center control, and simulates natural decision delays.
- **Per-User High Score Persistence:** Tracks individual records using `localStorage` and JSON mapping, ensuring every username maintains its own unique all-time high score.
- **Glassmorphism & Botanical UI:** Designed with a refined dark-emerald palette, glowing neon indicators (Mint Neon `X` and Emerald Lime `O`), and animated victory pulses.
- **Fully Responsive Architecture:** Dynamically scales grid layouts and interactive tiles across mobile devices, tablets, and desktop displays using CSS Grid and `clamp()` viewport units.
- **Touch & Mouse Ergonomics:** Uses CSS `@media (hover: hover)` logic and `:active` scale states to prevent sticky hovers on touchscreens while delivering tactile feedback.
- **Vanilla Core Architecture:** Built completely with lightweight Vanilla JavaScript without external dependencies or third-party game frameworks.

## 🛠️ Built With

- **HTML5:** Semantic game markup, dynamic modals, and input structures.
- **CSS3:** Glassmorphism UI, CSS Grid layout, neon glow filters, keyframe animations, and adaptive media queries.
- **JavaScript (ES6+):** Game state machine, strategic bot heuristic, DOM event handlers, and `localStorage` state management.
- **Google Fonts:** Clean and modern typography using the Outfit font family.
